# 3Dオブジェクトのギズモ編集

## 使い方

ImGuiを有効にしたビルドでGAMEシーンを開きます。

1. 「オブジェクト編集」で「画面で3Dオブジェクトを編集」をON。
2. 画面上のPlayerまたはSphereを左クリック、または「編集対象」から選択。
3. 「操作」で移動・回転・拡縮を選び、表示されたハンドルをドラッグ。
4. 調整後に「選択対象を保存」または「全オブジェクトを保存」。

移動は軸の矢印や面、回転はリング、拡縮はハンドルを操作します。
ローカル／ワールド軸を選べます（拡縮はローカル軸）。スナップも指定可能です。
ギズモを動かすと、従来の数値編集と同じオブジェクトの値が変わり、
既存の `resources/data/game.json` への保存・復元をそのまま使用できます。
自動保存は行いません。

位置の編集には「デバッグカメラを使用」をONにするのがおすすめです。
追従カメラではPlayerを動かすとカメラも動きます。編集時にもゲームは動いているため、
ゲーム操作キーを押すとPlayerが移動します。ギズモにキーボードショートカットは割り当てていません。
ギズモのホバー・ドラッグ中はデバッグカメラとスプライトへのマウス入力を抑制します。

## 選択と登録

画面クリック時には、カメラの逆行列でマウス位置をレイへ変換し、登録対象の
ワールドBoundsと交差するか調べ、最も手前のものを選びます。
モデルの三角形そのものではなく、モデルを囲うAABBでの選択です。
非表示のオブジェクトは画面選択とギズモ描画の対象外です。
何もない場所をクリックすると選択を解除します。

現在は既存の編集対象であるPlayerとSphereに対応しています。
新しい対象はObjectSaveへGetter/Setterを登録し、ObjectEditor::RegisterObjectへ
固有ImGuiとBoundsGetterを渡すと、保存とギズモの両方で編集できます。
ギズモ用に別のTransformを保持せず、ObjectSave::TryGetValues / ApplyValuesを通して
同じ実体へ反映します。登録情報はシーン終了時に解除します。

描画はゲーム画面全体を対象にしています。別のRenderTexture上にゲーム画面を
埋め込む場合は、その描画領域に合わせてギズモと選択レイの領域を変更する必要があります。

## 使用ライブラリ・検証

ハンドルの操作にはImGuizmo（MIT License）を使用しています。
`externals/ImGuizmo/README.TKMAX.md` に取得元と固定リビジョンを記載しています。
Debug / USE_IMGUIで使用し、ReleaseではImGuizmo.cppをビルドから除外します。

Linux上で実際のImGui / ImGuizmoにマウス入力を与え、移動・回転・拡縮のドラッグと
操作終了時のキャンセルを検証しました。実際のObjectSaveを使った編集・保存・復元、
レイの逆投影、手前・背面・描画範囲外の選択、非一様・ミラー拡縮を含む回転の往復も検証済みです。
Windowsのカメラ・ファイル置換APIは検証時に代替し、DirectX描画は使用していません。
Windowsでの全体ビルドと実画面の操作は未検証です。
