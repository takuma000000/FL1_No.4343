# ポストエフェクトの選択

ImGui有効ビルドで起動すると、全シーン共通の「ポストエフェクト」ウィンドウが表示されます。
「表示する効果」から、ラジアルブラー・波紋・ビネット・オーラ・霧・ノイズ・スピード線・モーションブラーを選べます。
選択した1種類だけを表示し、その効果の調整項目だけが表示されます。
波紋は繰り返し再生します。ラジアルブラーの強さは既存シェーダーの固定値です。

- 「なし」: ポストエフェクトを適用しません。
- 「ゲームの設定」: 従来の各Effect::IsActiveによる制御に戻します（起動時の初期状態）。
- 「ゲームの設定に戻す」ボタンでも確認用の選択を解除できます。

効果はオフスクリーン描画した背景・3Dモデル・パーティクルに適用します。
その後に描画する前面スプライト、シーン遷移フェード、ImGuiは対象外です。
確認用選択とパラメータは起動中のみ保持し、ファイルには保存しません。
ライトやモデルの設定は変更しません。

PostEffectEditorはMyGameが一つ所有し、各シーンへの追加コードは不要です。
既存のEffectクラスの所有権や有効フラグを変更せず、描画時の選択だけを上書きします。
必要な描画パイプラインは初回使用時に初期化し、以降は再利用します。
モーションブラー選択直後は現在フレームで履歴を作り、次フレームから残像を表示します。

GPU部分を代替した検証で、8種類の切り替え、パラメータ転送、なし／ゲーム設定への復帰、
既存Effectの状態保持、モーションブラー初回の描画先を確認済みです。
ImGuiコードの構文検査とVisual StudioプロジェクトのXML検査も実施しています。
Windowsの全体ビルド・実画面での見た目は未検証です。
