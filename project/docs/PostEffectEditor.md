# ポストエフェクトの選択

ImGui有効ビルドで起動すると、全シーン共通の「ポストエフェクト」ウィンドウが表示されます。
「表示する効果」から、ラジアルブラー・波紋・ビネット・オーラ・霧・ノイズ・スピード線・モーションブラー・漫画調（輪郭線＋トゥーン）を選べます。
選択した1種類だけを表示し、その効果の調整項目だけが表示されます。
波紋は繰り返し再生します。ラジアルブラーの強さは既存シェーダーの固定値です。

- 「なし」: ポストエフェクトを適用しません。
- 「ゲームの設定」: 従来の各Effect::IsActiveによる制御に戻します（起動時の初期状態）。
- 「ゲームの設定に戻す」ボタンでも確認用の選択を解除できます。

効果はオフスクリーン描画した背景・3Dモデル・パーティクルに適用します。
その後に描画する前面スプライト、シーン遷移フェード、ImGuiは対象外です。
確認用選択とパラメータは起動中のみ保持し、ファイルには保存しません。
ライトやモデルの設定は変更しません。

PostEffectEditorはMyGameが一つ所有し、各シーンへの追加コードは不要です。
既存のEffectクラスの所有権や有効フラグを変更せず、描画時の選択だけを上書きします。
必要な描画パイプラインは初回使用時に初期化し、以降は再利用します。
モーションブラー選択直後は現在フレームで履歴を作り、次フレームから残像を表示します。

GPU部分を代替した検証で、8種類の切り替え、パラメータ転送、なし／ゲーム設定への復帰、
既存Effectの状態保持、モーションブラー初回の描画先を確認済みです。
ImGuiコードの構文検査とVisual StudioプロジェクトのXML検査も実施しています。
Windowsの全体ビルド・実画面での見た目は未検証です。

## 漫画調（輪郭線＋トゥーン）

「表示する効果」から「漫画調（輪郭線＋トゥーン）」を選びます。
初期設定は黒い輪郭線＋3段階の明暗です。

- 輪郭線: ON/OFF、色、不透明度、太さ（1～5ピクセル）、境界の判定しきい値。
- トゥーンの明暗: ON/OFF、段階数（2～8）、強さ（0～1）。

しきい値を小さくすると細かな深度変化にも線が出ます。太さはピクセル単位に丸めて使います。
個別のチェックを外すと、輪郭線だけ／トゥーンだけでも確認できます。
他の効果・なし・ゲームの設定へ切り替えると通常のライティングに戻ります。

輪郭線は3D描画の深度を逆投影し、逆深度の二階差分から境界を求めます。
緩やかな平面の傾きやテクスチャの柄そのものには線を付けません。
同じ深度で接する面など、深度に変化がない境界は検出できません。
半透明パーティクルやスプライトのように深度を書かない描画物にも輪郭線は付きません。
前面スプライト・シーン遷移フェード・ImGuiは既存どおり対象外です。

トゥーンは画面の色数を減らす処理ではなく、Object3dのピクセルシェーダーで
平行光源・ポイントライト・スポットライトの拡散反射とハイライトを段階化します。
テクスチャの色や模様は保持します。ライティング無効のマテリアルには適用しません。
既存のライト位置・色・強さ、モデルやパーティクルの保存データは変更しません。

深度はTypelessリソースを既存のD24 DSVとR24 SRVで共有します。
Swapchainへの切り替え時は3Dの深度を消去せず、輪郭線処理で読み終えたらDEPTH_WRITEへ戻し、
次フレームのPreDrawで従来どおりクリアします。深度SRVと描画パイプラインは初回だけ生成します。

DXCで新規Comic.PS.hlslと変更したObject3d.PS.hlslを、実行時と同じps_6_0 / -Zprでコンパイル済みです。
C++とHLSLの定数バッファ配置（112バイト）、通常表示への復帰、深度の読書き状態遷移を検証済みです。
Windowsでの全体ビルド・実画面の見た目は未検証です。

## LineRendererの補助線

LineRenderer::Drawは頂点とカメラ行列を予約し、MyGameがポスト処理後にFlushします。
コライダーの線とパーティクルエディタのグリッドは、漫画調を含むすべてのポスト効果の対象外です。
呼び出し側は従来どおりBeginFrame / AddLine・AddAABBなど / Drawを使えます。
補助線はモデルの深度で前後判定しますが、深度には書き込みません。
描画は前面スプライト・シーン遷移フェード・ImGuiより前なので、これらは補助線より上に表示されます。
