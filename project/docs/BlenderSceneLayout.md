# Blender連携とシーン配置エディタ

## モデルを用意する

1. `tools/blender/tkmax_scene_layout_export.py` をBlender 4.xのアドオンとしてインストールし、有効にします。
   更新した場合は修正版を入れ直してBlenderを再起動してください。
2. Blenderでメッシュ・マテリアルを作り、File → Export → TKMAX Scene Layout (.json)を選びます。
3. リポジトリ内の **`project/resources/blender_exports/任意の名前.json`** へ書き出します。
   blender_exportsフォルダがなければ作成してください。

OBJ・MTL・PNGは `resources/obj/blender_layout_assets/` に自動生成されます。
エンジン側へ画像を手動でコピーする必要はありません。
JSONにはBlenderの配置・名前・マーカーも残りますが、起動時には自動描画しません。
同一の形状・マテリアルは共有され、変更された資産には内容から決めた新しいファイル名が付きます。
元画像はBlenderで読める状態を維持するか、.blendへパックしてください。

## ゲーム内で配置する

GAMEシーンのImGui **「シーン配置エディタ」** を使います。

1. 「モデル一覧を更新」を押し、モデルを選びます。検索もできます。
2. 「選択したモデルを追加」を押すと初めて描画されます。追加位置は原点です。
   一覧で選択するだけでは描画しません。同じモデルも繰り返し追加できます。
3. 「配置済み」の一覧から一つ選び、位置・回転・サイズ・表示を編集します。
   回転の入力は度、保存データはラジアンです。名前変更はEnterで確定します。
   名前は配置とマーカー全体で重複しないものを指定してください。
4. 「複製」「削除」で選択中の配置を操作できます。
5. 「Undo」「Redo」で戻す・やり直す操作ができます。数値ドラッグ一回を履歴一回分として記録します。
   履歴は最大64回で、終了すると消えます。資産ファイルや保存ファイル自体は巻き戻しません。
6. 配置JSONに **`resources/layouts/scene.json`** などの保存先を指定し、「保存」します。
   別名に変えると別の配置として保存できます。保存確認では上書き先を確認できます。
7. 次回は同じパスを指定して「読込」してください。起動時は空の配置で始まります。
   「新規」で配置を空にできます。新規・読込もUndoで戻せます。

配置JSONを読むと、そこに保存された全配置を復元します。
Blenderでの配置を一括で再現したい場合は、配置JSON欄に
`resources/blender_exports/任意の名前.json` を指定して手動で読めます。
編集後は `resources/layouts/` の別ファイルへ保存してください。
Blender出力先へのゲーム側保存は防止します。

既に旧版で生成したOBJもモデル一覧から選択できます。
旧JSONは引き続き読めますが、新しいアドオンの書き出し先はblender_exportsです。
モデル名の表示はBlender出力JSONから取得します。対応するJSONがないモデルはOBJのファイル名を表示します。

## 保存とデータの扱い

- Blender出力とゲームの編集済み配置は別ファイルです。Blender再出力でゲームの配置は上書きしません。
- モデルはパスで参照します。モデル形状変更で別のハッシュ名になった場合、既存配置の参照は自動更新しません。
- 配置を削除しても、共有しているモデルやテクスチャは削除しません。
- 古いハッシュ名の資産は自動削除しません。読込済みのモデルも終了までキャッシュされます。
- 読込失敗時は現在の配置を保持します。保存は一時ファイルで検証してから置き換えます。
  既存ファイルは置き換えまで.bakに保持し、失敗した場合は復元します。
- `GetMarkers()`でEmptyの位置・名前・`tkmax_tag`を取得できます。読込済みマーカーは再保存時にも保持します。

## 対応範囲

静的なモデルの配置・描画が対象です。当たり判定、押し戻し、Playerや敵の生成、ライト、カメラは自動設定しません。
選択はImGui一覧で行います。3D画面のクリック選択や移動ギズモは実装していません。

BlenderのZ上向きからTKMAXのY上向きへの変換、左右の座標系、現行OBJローダーの
法線・面順序・UV規約を変換します。親子付けはワールドTransformへまとめます。

- 現在のビューレイヤーで表示され、レンダー無効でないメッシュを出力します。
- モディファイア適用後の静的形状・UV・コーナー法線に対応します。
- Base Colorの直接接続された画像または単色に対応します。プロシージャルな色は画像へベイクしてください。
- PBR全体、スケルトン、アニメーションの再現は対象外です。
- コレクションインスタンスは実体化してください。シアーのある親子Transformは整理してください。
- `tkmax_exclude`がtrueのものは書き出しません。Emptyはマーカーとして保存します。

## 検証

座標変換と実際のMyMathのTRSの一致、実際のOBJローダーの頂点・法線規約を検証しています。
配置エディタはGPU部分を代替して、空の起動・追加・複製・削除・Undo/Redo・保存/読込・
失敗時の保持・既存保存先の置換を検証しています。
ImGui側の構文検査とPythonの構文検査も実施しています。
Windowsの全体ビルドと実画面での操作は未検証です。
