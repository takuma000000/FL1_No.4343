# パーティクルエディタ

## 開き方

ImGuiを有効にしたビルドで実行し、「シーン移動」の移動先から
`PARTICLE_EDITOR` を選んで「シーン移動」を押します。
最初のシーンは従来どおりGAMEのままです。

専用シーンではゲームのPlayerや敵を動かさず、床グリッドと自由カメラで確認します。
右ドラッグで回転、左ドラッグで平行移動、ホイールで前後へ移動します。
ImGuiをマウスで操作している間はカメラ操作を受け付けません。

## 作成・調整

1. 「新規」、または保存済み一覧から設定を選んで「選択した設定を読み込む」。
2. 「再生 / もう一度発生」でプレビュー。「一時停止」「再開」「停止・粒子を消す」も使用可能。
3. 発生数・発生間隔・発生範囲・初速度の範囲・重力・寿命・形状・テクスチャを調整。
4. 開始／終了の色・サイズを調整。寿命に沿って直線的に変化します。
5. エフェクト名を入力して「保存」。同名ファイルがある場合は「上書き保存」で確定。

「前の粒子を寿命まで残す」をONにすると、再生ボタン・設定調整・連続発生時に
生存粒子を消さず、新しい粒子を追加します。OFFでは次の発生時に前の粒子を消します。
炎・煙は「連続発生」と「前の粒子を寿命まで残す」を両方ONにしてください。
形状・テクスチャはグループ共有のため、変更時だけ生存粒子を消します。
最初から確認したい場合は「停止・粒子を消す」後に再生してください。
この設定はJSONのkeepParticlesに保存され、ゲームの再生にも適用されます。
旧JSONにこの項目がない場合はONとして読み込みます。
連続発生OFFは一回だけ、ONは停止するまで指定間隔で発生します。
プレビュー位置とカメラは保存されず、ゲームでは再生時に指定した位置を使います。
テクスチャは `resources/texture` 内から選べます。追加後は「一覧を更新」を押します。

名前は半角英数字、`_`、`-` の1～64文字です。拡張子は入力しません。
`resources/effects/<名前>.json` に保存します。数値不正やテクスチャ未発見の場合は
理由を表示し、既存ファイルを上書きしません。シーン移動前に必ず保存してください。

`sampleExplosion` を付属しています。読み込んで再生し、別の名前で保存して試せます。
現在は一つの発生源を持つエフェクトです。合成方式は既存の加算合成で、
複数レイヤーの組み合わせやブレンド方式の切り替えはまだありません。
リング・シリンダー・リボンも既存のカメラ向き描画を使用します。リボンは軌跡追跡ではなく板です。

## ゲームから使う

```cpp
#include "ParticleEffects.h"

// resources/effects/enemyExplosion.jsonを初回に自動読み込み。
// 以後は保存設定と描画用グループを再利用します。
auto* effects = TKM::ParticleEffects::GetInstance();
if (!effects->Play("enemyExplosion", enemyPosition)) {
    // GetLastError()に失敗理由が入ります。
}

// 移動する対象から発生させる場合、対象のUpdate後に位置だけ更新。
// 毎フレームPlayを呼ぶとEmitterが重複するので、一度だけPlayして使います。
effects->SetPosition("enemyExplosion", enemyPosition);

// 連続発生の停止と、その名前の生存粒子の消去。
effects->Stop("enemyExplosion");
```

GameSceneには既にParticleManagerの初期化・更新・描画があるので、
呼び出し側で個別のEmitter更新やCatalog登録を追加する必要はありません。
新しいシーンで使う場合は、そのシーンでもParticleManagerをInitializeし、
使用中カメラをSetCameraして、毎フレームUpdate・Drawを呼び出してください。
設定の再生・発生間隔の更新もParticleManager::Update内で行われます。

Playは一回目に設定をキャッシュします。外部でJSONを変更した場合は
`effects->Reload("enemyExplosion")` を呼ぶと、その後のPlayに反映されます。
エディタから保存した場合は自動でキャッシュも更新します。
同じ名前を複数位置で再生できますが、停止はその名前の全再生が対象です。
同名エフェクトはテクスチャと形状を共有するため、Reload後のPlayは既存粒子の見た目にも影響します。

一つの描画グループの上限は512粒子です。上限に達すると新規生成を見送り、生存粒子を寿命前に消しません。
発生数が多すぎる場合は、一回の発生数を減らすか発生間隔を長くしてください。
連続発生は最大64個、描画グループは既存分を含め128個までです。
シーン終了時のClearAllGroupsで粒子と連続発生を止めます。
GPUバッファとグループは再利用し、シーン往復やプレビュー再生ごとには増やしません。

## 検証範囲

Linux上で、JSON保存・復元・不正値拒否、再生スケジュール・停止・キャッシュ、
粒子の重力・色・サイズ補間・寿命・上限を、GPU部分を代替した単体検証で確認しています。
ImGui編集コードの構文検査とVisual StudioプロジェクトのXML検査も行っています。
Windows / DirectX12での全体ビルドと実画面の操作は未検証です。
